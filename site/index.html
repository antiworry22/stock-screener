항목별 판정 기준 · 데이터 소스 · 반영 위치

매일 처리 흐름

  1. 미장 종가 → 섹터별 미국장 충격 가중치 적용 (매핑표)
  2. 매크로 게이트 → 원/달러·미 금리·나스닥 급변 시 전체 점수 감산
  3. 전 종목 필터링 → 시총·거래대금 하한, 스팩·우선주 제외, 수정주가(adjusted)
  4. 지표 계산 → RSI·MACD·볼린저·이동평균·52주 위치·거래량·ATR
  5. 수급 계산 → 외국인·기관·연기금 연속 순매수, 한도소진율, 공매도 잔고, 국민연금 5% 공시
  6. 실적·뉴스 → 최근 분기 YoY, 30일 공시 분류, 뉴스 감정점수, 목표주가 상승여력
  7. 종합 점수 → 지표·수급·실적/호재·섹터/미국장·안정성 가중합 (설정파일)
  8. 출력 → 수급 조합 TOP · 진입 화이트리스트+손절가 · 매수 금지 List · 조건검색
