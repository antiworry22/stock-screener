# clx — CHARTLAB 6축 엔진 (첨부 chartlab_engine 이식·보완판)

수집(collect.py)이 매일 전 종목 일봉(약 380개)에 돌려서
- latest.json 의 종목마다 `cl` 요약(점수·판정·6축·패턴·손익비·체크리스트)
- 보관 칸 `live-cl` 브랜치에 `{종목코드}.json` (일봉 + 전체 분석 결과)
를 만듭니다. 화면(site/assets/chartx.js)이 이것을 그립니다.

## 원본 대비 보완 (가이드 문서 기준으로 바로잡음)
1. 삼각형·쐐기 판정식 교정 — 원본은 상승 쐐기를 '벌어질 때'로, 대칭 삼각형은 사실상 잡히지 않게 되어 있었음. 추세선 적합도(R²≥0.5)·3점 이상 조건 추가
2. 측정 목표가(가이드 5장) 계산 추가 — 이중바닥/천장·(역)헤드앤숄더·삼각형·쐐기·박스·깃발·컵앤핸들·돌파
3. 돌파 확인 여부 — 넥라인·돌파선 확인 전 패턴은 점수 반영 절반 (가이드 "돌파 확인 뒤에만 유효")
4. 이중천장/바닥 — 최근 30봉 안 + 골/봉우리 5% 이상 + 6개월 범위 위/아래쪽에서만 (원본은 너무 자주 잡힘)
5. 손절가 — 가이드 9장 "지지 하단과 2×ATR 중 더 가까운 쪽"(원본 코드는 더 먼 쪽) + 최소 1×ATR
6. 목표가 상한 6×ATR(목표2 10×ATR) — 큰 하락 뒤 먼 저항 때문에 손익비가 비현실적으로 커지는 것 방지
7. 신고가 돌파에 거래량 1.5배 미만이면 '가짜 돌파 주의'(10계명 ⑤)
8. 집게형(쌍바닥/쌍봉) — 원본은 저가만 같으면 매일 잡힘 → 추세 끝 + 색 전환일 때만
9. 진입 전 5초 체크리스트·10계명 경고·손익비 1.5 미만 진입 보류 문구 추가
10. 속도 개선(같은 결과): 가중이동평균 합성곱, 스윙포인트 rolling, 캔들 검사 구간 축소
